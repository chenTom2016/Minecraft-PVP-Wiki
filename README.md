# Minecraft PVP知识库

你好，欢迎来到这里。

这里是一个关于 **Minecraft Java 高版本 PVP 的完整知识库。它不是普通的「技巧合集」，而是一套**可以照着练、能判断自己是否真的掌握**的教程文档。

> [!NOTE]
> 本文档采用 **Microsoft Learn 风格**的文档结构（面包屑 → 标题 → 本文内容 → Note 提示 → 表格 → 代码块），便于在 GitHub 上阅读、检索与长期维护。

## 这个仓库是什么？

| 项目     | 说明                                     |
| -------- | ---------------------------------------- |
| **内容** | Minecraft Java 1.21.11 高版本的 PVP 教程 |
| **语言** | 中文                                     |
| **格式** | 纯 Markdown，GitHub 直接渲染，无 emoji   |
| **定位** | 博客式实战教程 + 训练手册 + 知识库索引   |
